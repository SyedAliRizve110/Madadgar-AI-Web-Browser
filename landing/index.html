How to Install Madadgar in 2 Minutes

No Chrome Web Store account needed. Installs cleanly via Developer Mode.

1

Download & Extract

Download madadgar-v1.0.0.zip and extract the folder to your computer.

2

Open Extensions Page

In Chrome, navigate to chrome://extensions and toggle the Developer mode switch in the top-right corner.

3

Load Unpacked

Click Load unpacked and select the extracted extension folder (or the dist/ directory).

4

Add Free API Key

Click the Madadgar icon in your toolbar, open Settings, and enter your free Gemini API key from Google AI Studio.
